How the tables connect
Profiles→installed on→SIM cards
via Profile installations (tracks which profile is on which SIM, and when)
SIM cards→subscribed to→Bundles
via SIM card plans (tracks plan changes: activations, upgrades, swaps)
Bundles→priced by→Rate cards
rates vary by country, network, and technology (4G vs 5G)
Profiles→generates→Usage events
each data usage session is recorded as an event
Network tech→classifies→Usage events + Rate cards
lookup table that maps all tech names (LTE, 4g, NR...) to standard codes (4G, 5G)
PK = primary key (unique identifier for each row) • FK = foreign key (links to another table's primary key) • Orange badges = validation rules the database enforces automatically.
Date ranges use NULL to mean "still active" — no end date means the record is current.
